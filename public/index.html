📋 How to Get Real Credentials
LinkedIn 1. Go to linkedin.com/developers
2. Create a new app
3. Add your company page
4. Enable: Share on LinkedIn, Sign In with LinkedIn
5. Copy Client ID + Secret
6. Add redirect URI shown above
Instagram 1. Go to developers.facebook.com
2. Create a new app (Business type)
3. Add Instagram Graph API product
4. Link your Instagram Business Account
5. Copy App ID + Secret
6. Add redirect URI above
Facebook 1. Use same app as Instagram
2. Add Pages API product
3. Enable manage_pages permission
4. Submit for App Review (for production)
5. Add redirect URI above
